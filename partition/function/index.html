iceberg_hash, the hash allowed on the column side of a partition rule.

The hash decides which region a row is written to and is persisted in partition metadata, so its result for a given input must never change across versions. A different algorithm needs a new type.

Rule simplification and coverage checks treat the hash as an independent dimension, which holds because it is defined for every value of the accepted column types.
