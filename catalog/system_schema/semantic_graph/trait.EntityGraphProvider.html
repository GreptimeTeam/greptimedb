Expand description

Produces the rows of the computed entity-graph tables at read time.

Implemented above the query engine (in the frontend) and injected into the catalog manager after construction — the provider needs the engine, which needs the catalog manager — so this late binding breaks the catalog -> query dependency cycle.

query_ctx is the outer query’s context, captured when the computed table is resolved: the derivation must read only sources that context may read and execute under it, inheriting the caller’s permissions, cancellation and deadline (the RFC’s derivation contract). None (context-less internal resolution) keeps the provider’s default behaviour.
