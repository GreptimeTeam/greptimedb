Module vector_match 

Source
Expand description

Vector–vector binary and set operations over evaluated series on one grid.

Semantics follow Prometheus VectorBinop, VectorAnd, VectorOr and VectorUnless at every grid point. Cardinality rules are checked per point: series sharing a match group conflict only where both are present. Each field is matched on its own; the results of all fields with one label set form one series.
