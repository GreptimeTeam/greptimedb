Module vector_match 

Source
Expand description

Vector–vector binary and set operations over evaluated series on one grid.

Semantics follow Prometheus VectorBinop, VectorAnd, VectorOr and VectorUnless evaluated at every grid point. Series are processed whole, over their own grid ranges, and the cardinality rules are checked per point: series sharing a match group only conflict at points where both are present. Each field is matched on its own, as if the operands held only that field; the results of all fields with one label set form one series.
