The bytes the merge of every field’s results and the builder writing them out allocate.

The merge files every kept triple under its label set and hands one series per label set to a builder, so the triples, the table, the row it fills, the output vector and the builder’s own buffers are alive together: one triple of a label set’s samples, the span a run may start with, a row of the histogram table per histogram and the heap its buckets are copied to. Every term counts a value a field actually kept or a label set it filed, so a pair the operator filtered costs its label set – the table holds one without a value – and no row at all. What grows with the output rows is the builder’s columns, which merge_fields reserves in blocks as it pushes them.
