promql::histogram_eval

Module legacy_bridge 

Source
Expand description

The legacy native-histogram estimators, delegated to the native kernel.

prom_native_histogram_quantile and prom_native_histogram_fraction used to estimate with the bucket walk inside NativeHistogram itself: exponential bucket bounds computed as 2^x, and a forward walk from the lowest bucket only. The native kernel (histogram_eval) walks the same histogram the way Prometheus does – the bound table in bounds and, for a quantile above the median of a histogram whose sum is not NaN, a walk from the highest bucket down – so keeping both estimators leaves two answers for one histogram that differ in their last places.

These functions read a [NativeHistogram] through the borrowed [HistogramView] that both representations share, hand it to the kernel as the FloatHistogram the kernel owns, and return the answer in the shape the legacy UDFs report it. The scalar arithmetic – add, sub, scale, divide_by – takes the same route below the estimators, so Prometheus’s rules for reconciling a zero bucket, reducing a schema and intersecting custom bounds live in one place.
