promql::histogram_eval

Module legacy_bridge 

Source
Expand description

Legacy [NativeHistogram] quantile, fraction and arithmetic, evaluated by the native kernel so both paths share one implementation of Prometheus’s histogram rules. Each function reads the histogram through a [HistogramView] and returns results in the legacy UDFs’ shape.
