Module float_histogram 

Source
Expand description

Arithmetic on owned native histograms, following Prometheus FloatHistogram (model/histogram/float_histogram.go): Add, KahanAdd, Sub, Mul, Div, Compact, CopyToSchema, DetectReset and Equals, including zero bucket reconciliation, resolution reduction and the intersection of mismatched custom bounds.

Each side is a list of (bucket index, count) sorted by index. Go splices span layouts in place; the bucket indices and the order of additions to each bucket do not depend on the layout, so the results are the same.
