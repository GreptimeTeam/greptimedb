Histogram functions over evaluated series: histogram_quantile and histogram_fraction over classic and native histograms (Prometheus funcHistogramQuantile, funcHistogramFraction and resetHistograms), and histogram_count, histogram_sum, histogram_avg, histogram_stddev and histogram_stdvar over native histograms.

histogram_quantiles
histogram_quantiles(v, label, q...): evaluate_histograms with Quantile(q) for each q, each result labelled with label set to q as Prometheus’ FormatOpenMetricsFloat writes it. Results that then share a label set merge as merge_same_labelset does, so a repeated q, or a label that overwrites the label telling two histograms apart, fails at a point both hold. Each q is a constant; a per-step quantile is not supported here.
