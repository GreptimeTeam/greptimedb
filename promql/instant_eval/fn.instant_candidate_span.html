Expand description

Clips the candidate span using only the source axis endpoints; allocates nothing.

The caller validates step_ms > 0, lookback_ms >= 0 and the ordered query range. The wide count leaves each caller’s existing conversion to usize unchanged. The end is a scan bound, not necessarily a grid position when the query end is not aligned to its start.
