pub fn map_math_with_parameters(
    schema: &Arc<SeriesSchema>,
    series: &Series,
    function: ParameterizedMath<'_>,
) -> Result<Option<Series>>
Expand description

Applies function to every field with its parameters read at each point from time-varying scalars, and drops the metric name, as crate::map::map_math does with constant parameters; native histogram samples are skipped the same way.

A point where a parameter has no value has no result. clamp with max < min at a point has no result there, as Prometheus returns an empty vector for that step. None means no point holds a result. Same-labelset merging is left to the caller.

series is one evaluated series, which for max_of and min_of is the unlabelled one-field scalar their first argument evaluates to: those two are functions of two scalars, so what they map is the first of them and what they read per point is the second.
