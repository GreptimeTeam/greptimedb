Module info 

Source
Expand description

info(v, {selector}): the series of v with the data labels of the info series that share their identifying labels, following Prometheus combineWithInfoSeries and combineWithInfoVector.

Selecting the info series is the caller’s: the series whose name and data labels match the selector, evaluated at every point of the grid like an instant selector, with the value replaced by the original timestamp of the selected sample, as Prometheus’ evalSeries records it for info. This kernel only combines.
