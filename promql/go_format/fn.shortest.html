fn shortest(value: f64) -> (bool, String, i64)
Expand description

The fewest significant digits of a finite value that round-trip, without trailing zeros, and the position of the decimal point among them: value = ±0.digits × 10^point. Zero is "0" at point 1.

When two candidates of that length are equally close, Go takes the even one while Rust’s shortest formatting rounds up, so the digits are recomputed with Rust’s exact formatting, which rounds half to even. The recomputed digits only count when they still parse back to value: just above a power of two the lower neighbour is half as far away, so the even candidate can name that neighbour, and only the other one round-trips.
