PromQL comparison operators and sqrt(), which follow IEEE 754.

Arrow compares floats by total order, where NaN equals NaN and is greater than +Inf, and DataFusion’s sqrt rejects negative input. In PromQL every comparison involving NaN is false except !=, and the square root of a negative number is NaN. NULL input gives NULL output.

The functions report the column name of the expression they replace (a < b, sqrt(a)), so query output columns are unchanged.
