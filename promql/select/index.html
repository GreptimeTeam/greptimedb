Operators that depend on the whole set of evaluated series at each grid point: topk, bottomk, limitk, limit_ratio, scalar, absent and the instant-result sorts.

Semantics follow Prometheus (aggregationK, HashRatioSampler, funcScalar, funcAbsent, createLabelsForAbsentFunction, funcSort*). A scalar is a grid series without labels that has a value at every point, so vector(s) is s itself and has no kernel.
