Module raw_series_source 

Source
Expand description

A region scan that answers raw series frames with explicit labels.

A FusedSeries node runs inside a region when everything it reads is that region. A tree that reads two tables reads two regions, so the node has to run where both arrive, and each region answers with its own series instead. RawSeriesSource is that answer: it runs in the region, binds the region’s scan to one metric, its tags and fields, and hands the series on as one raw frame stream.

The frame names each series by its complete labels rather than by its storage key. The node’s schema is fixed while the frontend plans it, where the region’s key layout is unknown, and the receiver compares that schema exactly; an explicit frame depends only on the field names. Each scan partition is re-labelled independently, keeping its place in the partition layout and each series contiguous within its scan partition.
