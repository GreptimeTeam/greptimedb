Builds the physical node of a FusedSeries over the raw series its inputs can provide.

The node reads series frames. Below it is either the region scan itself, when the node runs in the region it reads, or an input that already produces explicit-label frames, when the node runs above the regions of several tables and each RawSeriesSource answered for its own. Anything else in between - a filter, a projection that drops the frame, an exchange - produces a different frame, or no frame at all, and this layer cannot look under it.

Ok(None) is therefore the answer for children that are neither: the logical plan is already fixed and DataFusion reports an unplanned extension node normally. A region scan that is found but refuses the raw path is a different case — the logical route chose this node for this scan and nothing here can undo that choice, because the logical plan is not available — so it is reported as an error that names the reason instead of silently producing no plan.
