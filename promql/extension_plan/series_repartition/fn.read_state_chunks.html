Expand description

Reads a child’s handed-over state, routing each group to the owner that folds it.

A state publication is not merged here: every group the child folded is one row of its export, and which owner folds it is the hash of its labels, exactly as a state frame’s row is routed. What differs is only the form - the group arrives as the child’s own chunk instead of as a batch - so the charge this node queues it with is grown while the child’s charge is still in hand, and the child’s own charge moves onto the groups rather than going with the publication it is for.
