Module split

Expand description

Where a native aggregate is split so two planes can run it.

A Complete aggregate is only correct when one execution reads every contribution. Over a partitioned raw-series scan, the innermost aggregate is split: the per-series prefix runs in each partition under a Partial aggregate, and the suffix above the cut runs over a Final aggregate of the merged state.

What cannot be split correctly is refused with [DataFusionError::NotImplemented], which the planner reads as “plan this query the existing way”.
