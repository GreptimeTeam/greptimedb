Module split 

Source
Expand description

Where a native aggregate is split so two planes can run it.

A Complete aggregate folds every contribution to a group, which is only correct when one execution reads all of them. A raw-series scan hands its partitions to separate executions, so the aggregate is split instead: the per-series prefix of the tree runs below the aggregate in the partitions that read series, that aggregate becomes a Partial one exporting the state each partition folded, and everything above it runs over the merged series.

The split is structural. The innermost aggregate of the tree is replaced by an input node at its own output - that is where state enters - and the nodes above it become the suffix. What cannot be split correctly is refused with [DataFusionError::NotImplemented], which the planner reads as “plan this query the existing way”.
