Rejects a bound state whose kind or component layout is not what this node binds.

Both halves matter. A frame carries its kind so a sum state is never merged as an avg one, and it carries the component list so a merge reads exactly the columns the producer wrote. The expected pair comes from the same binding the node was built from, so a histogram aggregate exports and accepts histogram state and a numeric one numeric state, with no second table to drift from the first.
