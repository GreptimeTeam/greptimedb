Module state

Expand description

The aggregate-state chunk a native Partial/Final aggregate passes between executions.

A state chunk carries a group’s labels, the grid positions it has contributions at, and the accumulator components its aggregate declares. Converting between kernel state (PartialAggregate) and frame state ([StateSeries]) keeps a field with no contribution absent rather than zero, so a later merge does not count it.
