Module runs

Expand description

The grid positions a field occupies, as sorted, disjoint runs.

A node that rewrites labels — a Map dropping the metric name, a Window dropping the name and the empty-valued labels — can turn two input series into one label set, and every layer above then reads the two chunks as one series. What decides whether that pair is legal is which positions of each field already hold a value: two values of one field at one position cannot be merged away, while a chunk that fills positions the set left empty merges cleanly, as crate::grid_series::merge_same_labelset does.

The native runtime’s partition-local [crate::native::execute::Emitted] table keeps this state per label set and field as runs, so a chunk of many positions costs one run rather than one entry per position.
