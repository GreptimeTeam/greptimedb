Module execute 

Source
Expand description

Running a bound tree, node by node.

Each execution owns a recursive runtime tree; the compiled NativeTree stays immutable, so one tree builds independent executions. A caller registers the tree’s per-node metric handles into its own metrics set once, before the execution starts.
