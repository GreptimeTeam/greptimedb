Module segment 

Source
Expand description

Segmenting a native tree, so each per-series prefix runs where its input is read.

A tree that reads across series answers one partition and gathers whatever it reads. Its per-series prefixes do not need that gather, so each is cut out as a FusedSeries node of its own and keeps the partitions it was scanned with: cut_as_segment decides what can be cut, cut_segments rewrites the tree into one segment per cut, and segment_tree builds the nodes, recursing into a cut that wraps a whole-vector consumer.

Everything here reads the bound tree alone. The columns a node publishes are the planner’s answer, so the builders ask for them through OutputTags, FieldNames and RootSchema instead of deriving them a second time.
