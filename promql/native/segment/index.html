Module segment 

Source
Expand description

Segmenting a native tree, so each per-series prefix runs where its input is read.

A tree that reads across series runs in one partition. Its per-series prefixes are cut out as FusedSeries nodes of their own so they keep their scan partitions: cut_as_segment decides what is cut, cut_segments rewrites the tree into one segment per cut, and segment_tree builds the nodes.

Output columns are the planner’s answer, read through OutputTags, FieldNames and RootSchema.
