promql::native

Module metrics 

Source
Expand description

Per-node metric handles for native PromQL execution and their DataFusion registration.

The whole native tree registers into the one [ExecutionPlanMetricsSet] of its enclosing operator (FusedSeriesExec), and readers aggregate by name, so each name carries the node’s path in the runtime tree: native.<path>.<metric>, with a metric from NodeMetric::ALL. The path is valid only within the topology that produced it; it is not a persisted or public identifier. peak_reserved_bytes alone is named native.p<partition>.<path>.<metric>, because a sum of peaks is not a peak.
