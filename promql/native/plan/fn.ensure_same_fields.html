Expand description

Checks that a node declares the field layout its input produces.

A window, a map, an instant selection and a complete aggregate all report one value per input field, so they keep the layout of their input. A node that declares a different number of fields than it consumes describes a computation this model has no meaning for, and letting it through would only surface at run time as a field count mismatch against a schema the tree was supposed to have validated.
