promql::native

Source
Expand description

The bound tree a native PromQL evaluation compiles to.

A query is compiled into NativeTree: NativeNodes whose operations are already bound to kernels, fields and grids. Nothing in this module interprets a function name, resolves a label or picks a column at run time; those decisions are made before the tree exists, so the hot path only feeds batches to kernels it was handed.

The tree is also the unit of legality. NativeNode::validate checks the contract every operation states about its input, which is what lets a new combination of supported operations be an ordinary tree instead of another hand-written shape.

What the tree cannot express yet is deliberate for this stage: NativeExpr::Scalar holds a constant, so time() and scalar(v) have no node. The legality below is therefore about the operations that exist, not about PromQL’s whole surface.
