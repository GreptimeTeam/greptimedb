promql::native

Module plan 

Source
Expand description

The bound tree a native PromQL evaluation compiles to.

A query is compiled into NativeTree: NativeNodes whose operations are already bound to kernels, fields and grids, so nothing here interprets a function name, resolves a label or picks a column at run time.

The tree is also the unit of legality: NativeNode::validate checks the contract each operation states about its input, so any combination of supported operations that passes it is executable.
