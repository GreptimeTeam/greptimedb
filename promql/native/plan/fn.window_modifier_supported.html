fn window_modifier_supported(input: &NativeNode, op: &BoundWindow) -> bool
Expand description

Whether the runtime evaluates op over input, with or without a range modifier.

An anchored or smoothed window reads samples around the window to pin its boundary values, which only a raw sample stream can offer and only a kernel that corrects its boundaries reads. That is one rule, not two: check_modifier states it for RangeEvaluator::try_new, and it is asked here over the schema the tree binds, so a modifier a runtime refuses is one admission declines.
