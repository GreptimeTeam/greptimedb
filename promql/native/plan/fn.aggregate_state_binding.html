pub fn aggregate_state_binding(
    kind: AggregateKind,
    field_kind: FieldKind,
) -> Option<(AggregateStateKind, Vec<StateComponent>)>
Expand description

Returns the state type implied by an aggregate over an input of field_kind, if that state can be merged across a partition boundary.

Two families share this table. A numeric input keeps the components the accumulator kernel declares, and the component list comes from that kernel rather than a second mapping, so changing a kernel’s state fields changes the native binding in lockstep. A native-histogram input binds the histogram state of the same aggregate: it carries the payload and the compensation that belongs to it, plus the evidence a merge of two partitions has to report. A quantile has no partial kernel at all, whatever it reads.
