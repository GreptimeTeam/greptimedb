pub(crate) struct AggregateRuntime {
    op: BoundAggregate,
    schema: Arc<SeriesSchema>,
    fold: Fold,
    annotations: Option<PromqlAnnotationCollector>,
    accumulator: Option<FloatAggregator>,
    retained: Option<QuantileInput>,
    merger: Option<FloatMerger>,
    state_schema: Option<Arc<AggregateStateSchema>>,
    pub(crate) computed: bool,
}
Expand description

One aggregate node’s states, from the first chunk it is handed to the series it finishes with.

Fields§

§op: BoundAggregate§schema: Arc<SeriesSchema>

The layout input and output share: an aggregate keeps its input’s fields and grid.

§fold: Fold§annotations: Option<PromqlAnnotationCollector>

Taken after the first annotation, so each node reports at most once.

§accumulator: Option<FloatAggregator>

None for Final and quantile, and once Self::compute has taken it.

§retained: Option<QuantileInput>

The whole input of a quantile; None for other kinds and once the kernel has answered.

§merger: Option<FloatMerger>§state_schema: Option<Arc<AggregateStateSchema>>§computed: bool

Whether Self::compute has run. The driver reads it to decide whether the node settled.

Source

pub(crate) fn hold_parameter( &mut self, parameter: Series, buffer: &mut NodeBuffer, ) -> Result<()>

Keeps the per-point φ series. The driver’s hold_scalar has already grown this reservation by series_bytes, so this only settles on QuantileInput::bytes instead of growing again.

Source

pub(crate) fn pending(&self, chunk: &EvaluatedChunk) -> usize

What consuming chunk reserves while it is consumed: its evaluated_bytes for a point-wise fold, which drops it after folding. A quantile returns 0 because Self::retain_quantile reserves the retained chunk itself; booking it here as well would bill it twice.

Source

pub(crate) fn accumulate( &mut self, chunk: EvaluatedChunk, buffer: &mut NodeBuffer, pending: usize, ) -> Result<()>

Folds one chunk into its group, or retains it for a quantile. A chunk’s is_last closes a member, not a group, so it is ignored.

Source

fn retain_quantile( &mut self, chunk: EvaluatedChunk, buffer: &mut NodeBuffer, ) -> Result<()>

Retains one chunk of a quantile’s input. The chunk’s descriptors plus the buffers and tables it is first to reference are reserved before the push, then the reservation settles on QuantileInput::bytes.

Source

pub(crate) fn accumulate_state( &mut self, chunk: StateChunk, buffer: &mut NodeBuffer, pending: usize, ) -> Result<()>

Merges one state chunk into this Final aggregate: either groups a local Partial folded (StateChunk::Series) or a decoded exported row (StateChunk::Row). Both are converted to the rows the merge kernel takes.

Source

pub(crate) fn pending_state(&self, chunk: &StateChunk) -> usize

Transient bytes required to consume a state chunk.

Source

pub(crate) fn groups(&self) -> usize

The number of groups, for sizing the output queue. A quantile has not grouped yet and reports its retained member count, an upper bound.

Source

pub(crate) fn compute( &mut self, buffer: &mut NodeBuffer, queue_bytes: usize, ) -> Result<Option<AggregateOutput>>

Finishes the fold and returns one series per group (or the state chunk of a Partial), or None if it already ran.

Source

fn report_evidence(&mut self, evidence: HistogramEvidence)

Reports histogram evidence once. A Partial reports nothing: a point’s outcome is decided only after the Final merge, and a collected message cannot be withdrawn.

Source

fn finish_quantile( &self, input: QuantileInput, buffer: &mut NodeBuffer, queue_bytes: usize, ) -> Result<Vec<Series>>

Answers a quantile from its retained input. φ is the held per-point series, or for a literal φ a series built over only the positions the input holds (not the span between them, which could be as wide as the grid). The reservation covers input, parameter and workspace while the kernel runs, then settles on the output after the input is dropped.
