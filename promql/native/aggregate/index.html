Module aggregate

Expand description

The run-time state of an aggregate node.

An aggregate folds each chunk into per-group state as it arrives and produces once, when the input ends. It cannot tell an incomplete group from a complete one: a AggregateStage::Complete aggregate is correct only if the plan routes every contribution to each group into this execution. Partitioned plans use AggregateStage::Partial and AggregateStage::Final, which carry kernel accumulator state between executions.

quantile has no fixed-width accumulator and no mergeable state, so it exists only as Complete and keeps its whole input until the input ends, when crate::aggregate::aggregate_quantile answers from it. There is no spill: each retained chunk is reserved before it is kept, so an input that does not fit the pool is refused.
