fn child_segments(node: &NativeNode) -> Vec<(&NativeNode, Cow<'static, str>)>
Expand description

The child nodes of node and the path segment each is registered under, in child order.

The segments are the ones the runtime registers, not the names the bound tree happens to give the operands: info binds its operands as base and info, while the runtime registers them as the kernel’s left and right, so the display asks for the figures where they were put.
