promql::native

Module display 

Source
Expand description

One line per node of a NativeTree.

The tree is displayed by recursively visiting its bound expressions. The display is an observation of a compiled tree: it runs nothing, and every line reads as the node it is, making no claim about whether that node could run.

A node that recorded figures shows them at the end of its own line, and only its own: the walk carries the path the runtime registered that node under, so the figures of one node are never reported as those of another. A tree whose nodes recorded nothing - one that was never run, which is what EXPLAIN shows - prints structure only.
