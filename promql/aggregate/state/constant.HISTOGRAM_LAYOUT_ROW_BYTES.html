Bytes one one-row batch of the frame’s histogram layout costs before its bucket data.

Every column of the layout owns an Arrow array node with its own buffers, and that cost does not shrink for a histogram with one bucket: one row measures 2.6 KB whatever the bucket count, which is what a payload reports once the batch exists to be measured. It is rounded up here, so a batch whose bucket lists land at the top of their buffer capacity is covered too.
