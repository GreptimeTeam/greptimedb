Expand description

Evaluates range windows over raw series, one series at a time, handing out its results as they become final.

Each series is pushed as its chunks in order. A push evaluates the grid points whose windows the pushed samples complete, and hands them out as one EvaluatedChunk, so a consumer can stream a long series instead of waiting for its last chunk. One chunk may hold several runs of positions, separated by stretches holding no value, and the axis names them. The series closes on a chunk marked is_last, which is handed out even when it holds no position.

Fields are evaluated independently over their own valid samples; a row holding a stale marker in any field is dropped, as the ordinary range selector does. Only the samples later windows can still use are retained. Native histogram samples need a RangeFunction; an evaluator built from a bare kernel rejects them.

pub(crate) fn retained_bytes(&self) -> usize

An estimate of the bytes this evaluator keeps between pushes.

Counted by capacity, so it is what the storage holds rather than what it uses: the retained samples per field (timestamps, values, the reset index and the native histograms with the payload each of them owns), the row a push fills with the histograms it boxes, the identity of the open series and the pending batch’s own vectors. Left out are the kernel’s scratch buffers, this struct’s Vec headers and the grid, which every chunk addressed on it shares.

The figure is an estimate, not a ledger of every allocation: a histogram’s payload is measured once when it is admitted and released with it, so neither the retained samples nor the transient allocations of a push are walked again.

A push is the only caller that also holds the incoming chunk, and it charges that itself for as long as the call runs. The figure must not be per-chunk either: charging every chunk consumed would make the charge grow with the chunk count, so a fixed window over a long series would read as an allocation failure even though the window holds no more samples.

pub(crate) fn output_rows_bound( &self, last_ts: Option<i64>, last: bool, ) -> usize

An upper bound of the rows the next push hands out, for input whose last sample is at last_ts (None when it holds none) and which closes its series when last.

A push writes at most one row per point it decides, from the series’ cursor – the first point for a series not started yet. Unless the series closes, it decides no point past the time the input has reached; and a point holds a row only while its window still reaches the latest sample, so the points after that one’s window are decided empty. A replayed @ result fills every grid point from the one window it evaluates first.

pub fn push(&mut self, chunk: &RawSeriesChunk) -> Result<Option<EvaluatedChunk>>

Consumes the next chunk of the current series, or starts a new series.

Returns every position this chunk decided, in one chunk addressed absolutely on the evaluation grid; None when it decided no position holding a value. A decided position without a result is a row of no chunk, so the positions between two runs of one chunk hold no value and cost nothing. One push hands out at most one chunk.

A series always closes exactly once: on the chunk holding its last rows, or on an empty chunk after it when nothing is left. The evaluator must not be reused after an error.

Source

pub fn push_series( &mut self, series: &Series, last: bool, ) -> Result<Option<EvaluatedChunk>>

Evaluates one run of an evaluated series, such as the inner result of a subquery: the value at each grid point is a sample at that time. Stale markers are kept as values, since the input is computed.

last says whether this delivery closes its series. A stream hands over the same logical series more than once – a prefix now, its closing chunk later – and the windows of a later delivery read the samples of the earlier ones, so the state a series retains lives on across them: only the last call ends it. Handing the deliveries over without saying which is last would close the series early and lose exactly the samples a window across the boundary needs.

One delivery may hold several runs of positions, separated by stretches holding no value; they all reach the caller in one chunk, addressed by the axis. A delivery that holds no position at all is a legal close when it is last, and an error otherwise.

fn close_series(&mut self) -> Result<Option<EvaluatedChunk>>

Evaluates the rest of the series of the last input chunk and closes it.

The rows still buffered are handed out here as one chunk, and the chunk that sees nothing behind it carries is_last.

Source

fn emit(&mut self) -> Result<Option<EvaluatedChunk>>

Hands out the rows buffered so far as one chunk, and closes the series when nothing is left.

The chunk holds every row decided since the last hand-out, in one go and in one [Series]: several runs of positions may sit inside it, separated by stretches holding no value, and the axis names them. A position decided to hold none costs no row, so it lies between the runs rather than inside one. is_last closes the series, and a series always closes exactly once: on the chunk that carries its last rows, or on an empty chunk after it when no row is left.

fn ingest_in_bulk( &mut self, timestamps: &[i64], fields: &SeriesFields, drop_stale: bool, ) -> bool

Appends the chunk in bulk when every field is an entirely present, unshifted float column.

Returns false when any condition of the per-sample path applies, so the caller can run it. A chunk carrying a stale marker takes that path too: the marker drops the whole row, and reproducing that here would cost the same scan the loop already makes.

A field mixing floats and native histograms never qualifies: dense() reports [DenseSamplesRef::Mixed] for it, keeping its windows on the histogram path where the mixed-window rules decide the result.
