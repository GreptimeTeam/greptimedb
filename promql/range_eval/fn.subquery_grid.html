pub fn subquery_grid(
    outer: GridSpec,
    window: RangeWindow,
    step_ms: i64,
) -> Result<Option<GridSpec>>
Expand description

The inner grid of a subquery read by window from the outer grid outer: the multiples of step_ms after start - F - range up to the last window end, where F is the fold offset of window; with @, the only window end is start - F. None when no multiple falls in the windows.
