pub(crate) async fn fetch_listed<T, F>(
    objects: impl Stream<Item = Result<ListedObject>>,

) -> Result<(Vec<T>, Vec<(u64, Error)>)>
where
    F: Future<Output = Result<T>>,
Expand description

Fetches objects as they are listed with fetch, up to concurrency objects at a time, and returns what the fetches returned, in the order they complete, and the listed objects the object store no longer had, with the error the fetch met. A failed listing or any other failure abandons the remaining fetches.
