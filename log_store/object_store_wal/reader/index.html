Read-only access to another node’s immutable WAL objects.

Structs§

CachedObject 🔒
Cached metadata for an immutable WAL object, without recovery release records.
NodeWalPrefix
A normalized WAL node prefix: <root>/datanodes/<node>/epochs/<generation>. Construct it from a persisted source prefix or ObjectStoreWalConfig::node_prefix.
ObjectStoreWalReader
Reads remote WAL ranges without claiming an epoch or modifying the source. The reader never honors missing-history or corrupted-segment skip options. It does not own region roles, manifests, release positions or replay tasks.
ObjectStoreWalReaders
Readers shared by source prefix on one destination node and one WAL backend. Keep this registry for the node’s lifetime, and hold each returned reader while any recovery range still references that source. Dropping the last reader releases its cached indexes; no background task or writer is started.
