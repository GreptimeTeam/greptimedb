Constant MAX_FAILING_RETRY_DELAY 

Source 
const MAX_FAILING_RETRY_DELAY: Duration;
Expand description

Longest delay from a failed attempt of a backlog that the object store refuses with an error that requires intervention, see Failing, to the next attempt. The delay doubles from CREATE_RETRY_DELAY after every attempt. At the cap a dead bucket costs four requests a minute, a conditional create and the read that reconciles it every 30 seconds; a longer cap would keep appends rejected longer after the cause is fixed.
