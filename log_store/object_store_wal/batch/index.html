Accumulation of admitted entries into the batch that becomes the next object, and the entry id scheme.

Structs§

OpenBatch 🔒
Entries admitted since the last seal, together with the position of the last entry admitted per region.

Constants§

OBJECT_SEQ_LIMIT 🔒
Object sequences are 0..OBJECT_SEQ_LIMIT, the 44 bits an entry id leaves above the position.
POSITION_BITS 🔒
Bits of an entry id that hold the position of the entry among the entries of its region inside the object; the remaining high bits hold the object sequence.
POSITION_LIMIT 🔒
Positions are 1..POSITION_LIMIT, so an object holds at most 2^20 - 1 entries of one region and a batch seals before a region reaches the limit. This is a theoretical bound: an object is sealed by size long before.
