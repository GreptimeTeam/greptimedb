CacheMetrics
Caller-bound metrics for native cache loading. No collectors are registered here. Requests count only try_get_with calls, including its cache hits and callers sharing another request’s load. Plain get calls are not counted. Loads count only loader futures actually polled by the backend; their difference is not a waiter count.
CacheSizeMetric
A byte metric with labels bound for one or more cache instances.
CacheSizeMetrics
Cache byte metrics combining manually maintained gauges and sampled cache weights. Sampling does not force backend maintenance or include pending loader values.
