pub struct PagedCache<K> {
    cache: Cache<(K, u64), Arc<CachedPage>>,
    page_size: u64,
    observer: PageCacheObserver,
    _capacity_registration: CacheSizeRegistration,
}
Expand description

Caches fixed-size byte pages of immutable content identified by K. File identity must include any version needed to distinguish different contents. Missing pages elected by this fetch are submitted through [RangeReader::read_vec].
