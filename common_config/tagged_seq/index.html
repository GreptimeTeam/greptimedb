Module tagged_seq 

Source
Expand description

Environment overrides for configuration keys holding a sequence of tagged tables.

Such a sequence is what a Vec of externally tagged enums serializes to, for example the region_engine option:

[{"mito": {...}}, {"file": {...}}]

Handing the plain [Environment] source to config cannot work for these keys: config writes every flat dotted key by walking down its path, and the walk resets any intermediate value that is not a table. Walking region_engine.mito.index.aux_path therefore destroys the default sequence before anything is set.

This source instead addresses the entries by their tag name and merges the overrides onto the matching default entries:

GREPTIMEDB_STANDALONE__REGION_ENGINE__MITO__INDEX__AUX_PATH=...

Entries that only the environment mentions are appended, and every field that is not mentioned keeps its default value. A configuration file that configures the whole sequence replaces the merged one, which makes these variables ineffective; the file has to spell out every entry it wants.
