Module partition_compat 

Source
Expand description

Rejects an ALTER TABLE whose column type changes would break the persisted partition expressions of a region, before any region is altered.

Bounds keep the type they were written with. Row routing compares them with row values as Values, which only stays valid across a timestamp unit widening; scans coerce the bound to the common comparison type, which can overflow (a millisecond bound in year 3000 cast to nanoseconds).

partition depends on this crate, so the Persisted* types mirror the JSON of partition::partition::PartitionBound and partition::expr::PartitionExpr. A test in partition runs real serialized expressions through this validator.
