fn utf8_list_literals(
    values: &ArrayRef,
    max_values: usize,
) -> Option<Vec<Arc<dyn PhysicalExpr>>>
Expand description

Materializes the IN list literals for a build-key membership.

This is the authoritative value check: the list is only built for a non-empty, NULL-free, non-dictionary Utf8 array of at most max_values entries. max_values is checked before a [Literal] is created for every build key, so an over-large build side is refused instead of being materialized and then measured. The caller has already been through RemoteMembership::from_lookup, so a refusal here can only be the count bound and is reported as a size refusal, not as a missing wire form.
