Module series_frame 

Source
Expand description

Streaming boundary between finite raw-series chunks and DataFusion record batches.

Schema fields identify the ordered logical payload fields and codec layout; additional application metadata is permitted when stable across the stream. A key-encoded frame also declares its own label decode description, and the frame is the sole source of decode information: unpack_raw_series reads the fields, the label mode, the description, and the producer ordering from the received schema, keeps the description on the returned stream, and therefore needs no [RawLabelSource]. A caller that holds a scan-bound identity — the physical region key layout a decoded identity came from — compares that identity’s declared label decode layout with ensure_frame_matches_label_source instead of passing it as a decode input; that comparison is equality of the description alone and proves nothing about region identity or provenance, and neither side is authenticated as field provenance. This adapter preserves scan candidates only; it is not a residual filter, authorization check, remote transport, or compaction boundary. Raw frames accept all three [SeriesOrdering] declarations, while evaluated frames accept only Contiguous. Raw Interleaved supports independently closed producer fragment chains in sequence, including recurring keys; it does not multiplex open chains.

An evaluated frame is the same physical family: pack_evaluated_series and unpack_evaluated_series carry computed values under complete labels and grid positions, so a compute consumer needs neither a storage key nor a scan binding to read them.
