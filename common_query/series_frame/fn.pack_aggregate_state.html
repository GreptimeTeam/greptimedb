Packs aggregate-state chunks into bounded DataFusion record batches.

The producer supplies one [StateSeries] per group chunk; the cursor columnarises it into the frame once. Aggregate state requires a grid, explicit labels and contiguous ordering. The state schema is revalidated with its own constructor before any stream is returned.
