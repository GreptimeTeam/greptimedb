Expand description

Decides when a pending batch is ready without owning its payloads or execution.

A deadline wakeup must either allow flushing or produce a future deadline; otherwise the caller would repeatedly poll an expired timer.

fn should_flush<T>( &self, batch: &PendingBatch<T>, now: Instant, trigger: FlushTrigger, ) -> bool

Returns whether the batch should be flushed for this event at now.

Workers never flush empty batches, regardless of this decision.
