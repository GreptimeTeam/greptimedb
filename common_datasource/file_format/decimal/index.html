Module decimal 

Source
Expand description

Reads decimal and unsigned integer columns from the text of a csv or json file.

A file reader that decodes a number into a Float64 loses the digits a Float64 can’t hold. Arrow’s own decimal decoding is wrong for some numbers in scientific notation, and its json integer decoding goes through a Float64 for them. So the readers hand over the text of such a column and parse_number_columns parses it.
