Expand description

Returns a stream of the json file at path that reads the fields of schema.

Unlike the stream of a JsonSource, a string column also takes a number or a boolean, as the text it has in the file. So a column whose numbers must be parsed from every digit can be read as a string, see parse_number_columns.
