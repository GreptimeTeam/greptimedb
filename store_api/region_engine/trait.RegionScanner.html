Expand description

A scanner that provides a way to scan the region concurrently.

The scanner splits the region into partitions so that each partition can be scanned concurrently. You can use this trait to implement an ExecutionPlan.

fn raw_series_schema( &self, _label_source: &RawLabelSource, ) -> Result<Option<Arc<SeriesSchema>>, BoxedError>

Checks whether this scanner can provide a raw-series scan for the given labels.

This is a non-consuming preflight: it must not start a scan or otherwise consume scanner state. It checks immutable label binding, schema, and typed residual-predicate eligibility. Returning Some requires overriding scan_series_partition and promises that it can execute with this label source. None means the raw path is unsupported and an ordinary scan remains available. Execution must revalidate and return errors rather than falling back if the binding or schema changed since preflight.

fn raw_series_ordering(&self) -> Result<SeriesOrdering, BoxedError>

Returns the guarantee for subsequent raw scans without consuming scanner state.

Legacy raw sources have no ordering declaration, so Contiguous is the conservative default; Interleaved is not representable on the raw frame wire.

fn scan_series_partition( &self, _ctx: &QueryScanContext, _metrics_set: &ExecutionPlanMetricsSet, _partition: usize, _label_source: &RawLabelSource, ) -> Result<Option<SendableRawSeriesStream>, BoxedError>

Scans a partition as raw series when this source supports that path.

None means raw capability is absent before execution and permits a legacy scan instead. Some selects this entrypoint, including for an empty successful stream. Errors propagate; callers must not replay a failed raw scan through the legacy path. Use only one entrypoint for a given scanner partition per execution. The explicit label source is owned by the returned stream and must be bound to this scanner’s metadata snapshot.

Output preserves the ordinary storage reader’s pushdown and MVCC semantics. Inexact pushed-down predicates can leave false-positive candidates, just as in scan_partition. Implementations must preserve typed residual-predicate semantics before any lossy value conversion, or return None before execution when they cannot. Callers must retain residual predicate columns until those predicates are evaluated and apply the final projection afterward; raw capability does not mean filtering is complete.

§Panics

The default implementation panics. Implementations must override this method to support raw series scanning.

fn prepare_series( &self, _ctx: &QueryScanContext, _metrics_set: &ExecutionPlanMetricsSet, _label_source: &RawLabelSource, ) -> BoxFuture<'static, Result<Option<Arc<dyn PreparedSeriesSource>>, BoxedError>>

Prepares scanner-wide candidates once for independent ordinal-range reads.

Metadata I/O is asynchronous; sample payloads are loaded only by polling readers. The owned future does not borrow the scanner. None means unsupported before execution; errors must propagate without replay through a different scan path. Implementations may share preparation with their raw partition adapter.

Source

fn reset_state(&mut self)

Resets execution state after streams from the previous execution have been dropped.

Callers must not concurrently execute, reset, or install filters through scanner aliases. Implementations retaining dynamic predicates must discard them and derived pruning state, while preserving static predicates, the source snapshot, and prepared properties. The default is a no-op and does not make inherently one-shot sources replayable.
