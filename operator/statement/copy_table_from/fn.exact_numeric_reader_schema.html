Returns the schema to read the file with.

Schema inference reads a number as Int64 or Float64. Casting such a column to a wider table type afterwards rounds every value a Float64 can’t hold, and a value outside the Int64 range fails to parse. So a column that loads into a Decimal128 or UInt64 column is read as a string and parsed by [parse_number_columns], see text_number_columns.
