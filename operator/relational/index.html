Module relational 

Source
Expand description

Schema inference for the relational (external table) engine: connects to a remote MySQL database and maps its column types to GreptimeDB [ConcreteDataType]s at CREATE EXTERNAL TABLE time.

Types that cannot be mapped faithfully (e.g. BIT, spatial types, a DECIMAL wider than 38 digits, or TIME) are rejected rather than silently degraded. A few types map with documented caveats — DATETIME and TIMESTAMP lose their timezone semantics (see map_timestamp).
