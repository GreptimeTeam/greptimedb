fn read_field_type(data_type: &DataType, statement: &Expr) -> DataType
Expand description

The type the raw series scan hands one field of statement to the fused node as.

A numeric field reads as Float64 only where the existing plan also publishes Float64 (publishes_float_values); any other type is returned unchanged for the field-kind guard.
