Module native_compile 

Source
Expand description

Compiles a PromQL AST into a [NativeTree].

Each expression kind binds to one node, recursively: a selector to Input → Instant, a range function to Window over raw samples or over an evaluated subquery on its own grid, functions to Map or Vector, operators to Binary or Set, aggregators to Aggregate or Vector. Constant arguments are folded by constant_value. Any other shape is a [DataFusionError::NotImplemented] that quotes the accepted shapes.

Aggregates are bound as [AggregateStage::Complete]: the caller must feed every contribution to a group into one execution, or split the aggregation into Partial and Final.

Tree legality is checked by [NativeTree::try_new], not here. An Interleaved scan ordering is refused at the entry because no node can consume interleaved series.
