Binds absent_over_time(m[d]) into absent’s own vector operation, over a presence read of the window.

Both halves are absent’s: the labels come from the matrix selector’s matchers exactly as absent derives them from a vector selector’s, and the operation tests whether its input holds a series at each grid point. What differs is only where that input comes from — a matrix folds a window rather than selecting an instant — which is why the call is bound here and not by vector_call: absent_over_time reads a matrix, and nothing in it is a vector expression the recursion could compile.

The existing plan answers this call per series with a UDF, which needs a metric name to read a table from; a selector written without one names its metrics only by the labels that pick them, which is exactly the shape absent_over_time is asked for when nothing matches.
