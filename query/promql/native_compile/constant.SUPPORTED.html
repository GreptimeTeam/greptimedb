Expand description

The shapes this compiler accepts, quoted in every rejection.

It is one sentence of grammar rather than a list of examples, because it is what a refused query reads: the shapes have to be true of every query the compiler binds, and the examples only show them. The two matrix shapes and the recursion through them are stated first, because that recursion is what a reader is most likely to get wrong.
