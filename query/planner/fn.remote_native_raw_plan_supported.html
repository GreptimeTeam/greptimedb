fn remote_native_raw_plan_supported(plan: &LogicalPlan) -> bool
Expand description

A native plan a distributed planner splits over regions may place fused evaluation in one of two places: above one independent raw source per region, or inside the region whose own scan it reads.

The second placement is the analyzer’s to give. It moves a node into a region only when it classifies the node as running where its scan is, and a bare scan is never shipped across a region boundary on its own: nothing below the boundary could read it. So a scan is admitted only under a node the analyzer would move, and every other input of the plan has to be a raw source that names the region it reads.

A fused node that reads no region is the one exception: it has nothing to place in a region, so the frontend evaluates it and the transport this gate protects is never used.
