mito2::compaction::twcs

Module units 

Source
Expand description

Unit-based compaction picks for one TWCS window.

Picks select a contiguous interval of units in a fixed order. Grouping prefers rewriting related files together, but input limits and fallback paths may split groups or use single-file units. Separate admission checks preserve each pick’s progress guarantees under the assumptions below.

  • pick_active_l1 reduces the L1 file count of the active window.
  • pick_small_l1 reduces small L1 files without rewriting large peers.
  • pick_closed_merge only merges intervals of an inactive window whose outputs cannot add conflicts. Compaction outputs stay inside the bounding box of the inputs, so they can only overlap files intruding on that box.

When a window’s split-unit conflict graph is too dense to materialize, pick_closed_merge falls back to a bounded file reduction and admits it only when the same conflict bound holds.

§Termination

Let P be the number of conflicting file pairs (Extent::conflicts) in an inactive window and N its file count. A merge removes every pair among its inputs. Its outputs are one sorted run with no internal conflicts, so they only conflict with the I files intruding on the inputs’ box, at most outputs · I pairs. An inactive pick only merges inputs that had at least as many pairs with other files, so P does not grow; without intruders the inputs are closed and add no pairs. Every inactive pick either resolves a pair (P drops) or removes a file (P does not grow and N drops), so (P, N) strictly decreases in lexicographic order until the window receives new writes. Active-window picks may add conflicts, so each of them must remove a file: N strictly decreases.

The argument relies on how the compactor writes outputs:

  • Outputs hold a subset of the input rows, so each output’s time and key bounds lie inside the inputs’ bounding box.
  • Outputs are one stream in (key, time) order. For regions with a primary key, the writer only splits between complete series, so output key ranges are disjoint. Without a primary key, outputs have disjoint or touching time ranges. Neither is an Extent::conflicts pair.
  • A split only starts a new file once the current one reaches the size threshold, and outputs are not larger than inputs in total, so PickLimits::predicted_outputs bounds the output count.

test_closed_merges_terminate and test_active_l1_picks_terminate replay random windows with outputs written under these rules.
