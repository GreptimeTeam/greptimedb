PayloadDecoder 🔒
Scratch state for synchronous decoding of one sample block’s columns. The caller reserves decoded column memory before allocating this output buffer. A stream owns one decoder and reuses it for every block it reads; no buffer or context is shared with another stream or retained in a cache.
