check_bulk_insert_batch
Checks the batch of a bulk insert against the region schema with the rules WriteRequest::check_schema applies to rows: column names are unique, every column is a column of the region with its Arrow type and contains nulls only if the region column is nullable, and a missing column is nullable or has a default value. Tags may use any string encoding. Sparse batches carry the tags in one encoded primary key column instead. Returns whether the batch misses columns that the writer fills.

check_request_columns 🔒
Checks the columns of a write request against the region schema. Each column must be a column of the region, have its data type and, if the request carries one, its semantic type, and contain nulls only if the region column is nullable. check_missing checks the region columns that the request doesn’t have. Returns whether there are such columns.
