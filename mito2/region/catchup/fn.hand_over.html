Expand description

Hands a region whose manifest is published conditionally over to this node node_id, which becomes its writer, from the source node source_node_id that reported reported_entry_id as its last entry. Replays nothing.

The log store first hands the region over (see Wal::handoff). Then the catchup commits, after the manifest the region holds, this node’s handoff floor, the bound that hand-off returned, and, if the source has entries after where the manifest recovers its WAL from, a reported tail of the source over them, raising the committed sequence by HANDOVER_SEQUENCE_GAP. The tail is replayed in the background once the region is writable.

Returns the receipt of the manifest hook and the committed edit, which the region’s worker applies to the region’s version, in order with the edits of flushes and compactions.

A region that skips the WAL commits an empty edit and returns no edit. Fails, before the log store hands anything over, if the source has such entries and the request names no source, or if the region has no sequences left for another handover.
