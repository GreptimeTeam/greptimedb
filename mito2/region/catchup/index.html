Constants§

HANDOVER_SEQUENCE_GAP 🔒
How far a handover raises the committed sequence above the largest sequence this node knows the region used, in the manifest or on this node, so that writes accepted while the recorded tail is replayed outrank its rows. Those rows keep the sequences their source gave them, which this node does not know: the gap allows the source fewer than 2^40 sequences that the manifest does not record.
MAX_HANDOVER_SEQUENCE 🔒
The largest committed sequence a handover raises a region to, which allows about 2^22 handovers that record a tail. A handover that would pass it fails, leaving the sequences above it to the region’s writes, which allocate them without checking for overflow.
